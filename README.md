# سالم بلاي TV

مشغّل قوائم IPTV للتلفزيون (Android TV). التطبيق فارغ — تضيف روابطك بنفسك (M3U أو Xtream).

## تحميل التطبيق على التلفزيون
1. فعّل تثبيت التطبيقات من مصادر غير معروفة في إعدادات التلفزيون.
2. افتح تطبيق **Downloader** واكتب الرابط:
   `https://github.com/shmmuh8-design/salem-play/releases/latest/download/SalemPlay.apk`
3. ثبّت الملف وافتح "سالم بلاي".

كل تعديل يُرفع على `main` يبني نسخة جديدة تلقائياً.
